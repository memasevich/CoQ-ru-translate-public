# Публикация в Steam Workshop

Скрипт `Publish-Workshop.ps1` заливает папку `RussianLocalization` в Steam Workshop
через SteamCMD. Данные страницы мода (заголовок, описание, картинка, видимость)
берутся из `RussianLocalization/workshop.json`, версия — из `manifest.json`.

## Первый запуск

SteamCMD скрипт доустановит сам. Сначала нужно один раз войти в аккаунт и пройти
Steam Guard:

```powershell
.\_tools\publish\Publish-Workshop.ps1 -Account ваш_логин -LoginOnly
```

SteamCMD спросит пароль и код Steam Guard. Сессия сохранится, дальше код вводить
не потребуется, пока она не протухнет.

## Публикация

```powershell
.\_tools\publish\Publish-Workshop.ps1 -Account ваш_логин
```

Заливается ~52 МБ, это занимает несколько минут.

Заметку к обновлению можно задать вручную:

```powershell
.\_tools\publish\Publish-Workshop.ps1 -Account ваш_логин -ChangeNote "Перевод справки"
```

## Проверка без публикации

```powershell
.\_tools\publish\Publish-Workshop.ps1 -DryRun
```

Соберёт `workshop_item.vdf`, покажет его и остановится. Логин не нужен.

## Что важно знать

**Обновляется существующий элемент, а не создаётся новый.** `WorkshopId` берётся из
`workshop.json` (сейчас `3728849656`). Если поле пустое или равно нулю, скрипт
останавливается — иначе Steam создал бы дубликат страницы мода.

**Теги не трогаются.** SteamCMD обновляет только те поля, что есть в `.vdf`; теги
туда намеренно не пишутся, поэтому выставленные на странице сохранятся. Отдельно
стоит иметь в виду, что в `workshop.json` поле `Tags` — строка, хотя игра при
загрузке через свой интерфейс ждёт массив.

**Заливается вся папка мода целиком**, включая `untranslated.txt` и
`word_replacements.txt` — это заготовки сборщика текста, они были в сборке и
раньше. Чтобы залить что-то другое, укажите `-Source путь`.

**Файл скрипта должен оставаться в UTF-8 с BOM.** Windows PowerShell 5.1 читает
`.ps1` без BOM как ANSI и ломает кириллицу — скрипт просто не запустится.

## Альтернатива без SteamCMD

Тот же `workshop.json` умеет читать сама игра: Моды → выбрать мод →
Upload to Steam Workshop. Полезно, если со SteamCMD возникли проблемы.
