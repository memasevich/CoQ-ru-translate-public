# Глоссарий имён собственных

Единый канон передачи имён для русификатора Caves of Qud. **Перед тем как
переводить или править имя — свериться с таблицей.** Если имени тут нет,
решение принимается по принципам ниже и таблица дополняется.

Источник английского канона: `Caves of Qud\CoQ_Data\StreamingAssets\Base`
(`Factions.xml`, `Worlds.xml`, `Quests.xml`, `ObjectBlueprints\*.xml`) —
там лежат подлинные названия фракций, зон, квестов и уникальных существ.

## Принципы

1. **Один английский идентификатор — одна русская форма.** Падежные формы
   одного корня конфликтом не считаются; конфликт — это другой корень, другая
   транслитерация, дефис вместо пробела, перевод вместо транслита.
2. **Латинское H:** греко-латинские имена через **Г** (Hortensa → Гортензия,
   Herododicus → Герододик), семитские и «местные» — через **Х**
   (Hinnom, Chavvah, hindren → Хиндрен). Библейские имена — в синодальной
   традиции (Rebekah → Ревекка, Bethesda → Вифезда, Hinnom → Енном).
3. **Не ломать согласование.** Выбирая форму, смотреть, в каких фразах имя уже
   стоит: если сотня строк написана под мужской род единственного числа —
   канон берётся в мужском роде единственного числа (поэтому Six Day Stilt —
   «Шестидневный Столп», а не «Ходули»). Меняешь род — проверь прилагательные
   и глаголы прошедшего времени рядом.
4. **Несклоняемое лучше неправильно склонённого.** Если имя уже разбросано по
   готовым фразам как несклоняемое, склоняемая замена наплодит падежных ошибок
   (поэтому Otho — «Ото», а не «Отон»).
5. **Топонимы из двух слов — оба с заглавной** (Ржавые Колодцы, Радужный Лес,
   Красная Скала). Названия организаций — как сложилось в словаре.
6. **Игровые переменные `=name=`, `=factionaddress:X=`, `=verb:...=` и теги
   `{{C|...}}`, `<color=...>` не переводятся.** Переводится только текст после
   `|` внутри тега.
7. **Английское имя внутри русской фразы — это баг.** Такие остатки ищутся
   отдельным проходом (см. процесс).

## Процесс ревизии имени

1. **Собрать канон:** выдернуть подлинные имена из XML игры (см. выше).
2. **Найти все формы:** пройтись по `dictionary.json`, `word_dictionary.json`,
   `pattern_dictionary.json` регэкспом по корню и **посчитать частоты каждой
   словоформы** — решение принимается по данным, а не по первому впечатлению.
3. **Выбрать канон:** большинство побеждает, если оно не противоречит
   принципам 2–5. Осознанные отклонения записывать в колонку «примечание».
4. **Заменять по словоформам с падежным маппингом**, а не по подстроке.
   Многозначные слова (Templar, Spindle, Mechanimist, Stilt, Gyre) менять
   только там, где **английский ключ** содержит нужное имя.
5. **Проверить:** JSON валиден, старых форм не осталось, не появилось
   рассогласований (прил. + сущ., глагол прош. времени), BOM файлов не изменился.
6. **Морфология:** мусорные парадигмы-предложения из `morphology_dictionary.json`
   удалять, для нового канона добавлять правильную парадигму (6 падежей,
   ед. и мн. число). Ручной словарь имеет приоритет над `forms_dictionary.json`.
7. **Дописать строку в этот файл.**

## Осознанные исключения

- **Warden Une → «Настоятельница Уне»**, хотя Warden везде «Страж»: Уне —
  настоятельница святилища, титул выбран по смыслу.
- **Otho → «Ото»** — несклоняемое, см. принцип 4.
- **Corpus Choliys** в одном месте оставлен в скобках после перевода — это
  название лекарства, оригинал полезен игроку.

## Фракции

Падежные формы фракций живут в **`faction_cases.json`** (шесть падежей на
запись) — именно оттуда движок берёт название для строк репутации
(`TranslateFactionCase`). Если фракции там нет, движок сваливается в обычный
словарь и падеж теряется — поэтому **новую фракцию добавлять сразу с шестью
формами**. Ключ — английское имя как в `Factions.xml` (внутреннее `Name` или
`DisplayName`); движок сам пробует варианты с «The » и без.
