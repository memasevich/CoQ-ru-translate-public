# Система морфологии для русской локализации Caves of Qud

**Версия:** 1.1.0  
**Дата:** 2026-07-07

## Что нового

Добавлена система морфологии для автоматического склонения существительных и согласования родов. Это решает проблемы вроде:
- `You pass by a door` → `Вы проходите мимо дверь` (было) → `Вы проходите мимо двери` (стало)
- `You see a cave spider` → `Вы видите пещерный паук` (было) → `Вы видите пещерного паука` (стало)
- `with your desert kris` → `вашим пустынный крис` (было) → `вашим пустынным крисом` (стало)

## Архитектура

### Файлы

1. **MorphologyService.cs** — основной сервис морфологии
   - Загружает словарь склонений из `morphology_dictionary.json`
   - Кэширует результаты (до 50000 записей)
   - Применяет правила склонения для слов вне словаря
   - Обрабатывает маркеры `{{case:слово|падеж|род|число}}`

2. **morphology_dictionary.json** — словарь склонений
   - Содержит формы 6 падежей для ~100 ключевых слов Qud
   - Включает: существа, предметы, направления, абстрактные понятия

3. **morphology_patterns.json** — паттерны с морфологическими маркерами
   - Заменяет обычные паттерны из `pattern_dictionary.json`
   - Использует маркеры `{{case:{item}|gen|auto|sg}}` для склонения

## Использование

### Маркеры морфологии

Формат: `{{case:слово|падеж|род|число}}`

**Падежи:**
- `nom` — именительный (кто? что?)
- `gen` — родительный (кого? чего?)
- `dat` — дательный (кому? чему?)
- `acc` — винительный (кого? что?)
- `ins` — творительный (кем? чем?)
- `prep` — предложный (о ком? о чём?)

**Род:**
- `masc` — мужской
- `fem` — женский
- `neut` — средний
- `auto` — автоматическое определение (по словарю или окончанию)

**Число:**
- `sg` — единственное
- `pl` — множественное

### Примеры

```
{{case:щелкун|gen|masc|sg}} → щелкуна
{{case:дверь|gen|fem|sg}} → двери
{{case:пещерный паук|acc|masc|sg}} → пещерного паука
{{case:летучая мышь|nom|fem|sg}} → летучая мышь
{{case:юг|prep|masc|sg}} → юге
{{case:вода|gen|fem|sg}} → воды
```

### Автоматическое определение рода

Если указан `auto`, система определяет род автоматически:
1. Сначала проверяет словарь (`morphology_dictionary.json`)
2. Если слова нет в словаре — определяет по окончанию:
   - `-а/-я` → женский
   - `-о/-е` → средний
   - `-ь` → зависит от предыдущей буквы
   - согласная → мужской

## Тестирование

### 1. Проверка загрузки

Запустите игру и проверьте `Player.log`:
```
[RussianLocalization] MorphologyService loaded 100 noun forms.
```

### 2. Проверка в игре

Попробуйте следующие действия:
- Пройдите мимо двери → должно быть `Вы проходите мимо двери`
- Убейте пещерного паука → должно быть `пещерный паук погибает`
- Подберите предмет → должно быть `Вы берёте железный кинжал`
- Осмотрите существо → проверьте падежи в описании

### 3. Проверка логов

После игры проверьте `all_gameplay_texts.txt`:
- Ищите строки с `{{case:` — они должны быть заменены на склонённые формы
- Проверьте, что нет ломанных падежей

## Расширение словаря

Чтобы добавить новые слова в `morphology_dictionary.json`:

```json
{
  "новое_слово": {
    "Gender": "masc",
    "Singular": ["именительный", "родительный", "дательный", "винительный", "творительный", "предложный"],
    "Plural": ["именительный", "родительный", "дательный", "винительный", "творительный", "предложный"]
  }
}
```

**Порядок падежей:** Nom, Gen, Dat, Acc, Ins, Prep

## Известные ограничения

1. **Составные слова** — система плохо работает с составными словами типа `летучая мышь`. Для них нужно явно указывать формы в словаре.

2. **Прилагательные** — пока не склоняются автоматически. Нужно либо добавлять в словарь, либо использовать правила.

3. **Одушевлённость** — для винительного падежа (Acc) важно, одушевлённое слово или нет. Пока система считает все слова неодушевлёнными (Acc = Nom).
