# Русификатор Caves of Qud (Версия 1.0.0 - Global Polish Update)

Это публичная версия русификатора для тех, кто использует версию игры без Steam Workshop. В этой версии реализована система **умных паттернов**, которая обеспечивает правильную грамматику и склонения в большинстве игровых событий.

## 📦 Установка

1. Перейдите по пути: 
   `%AppData%\LocalLow\Freehold Games\CavesOfQud\Mods`
2. Создайте там папку `RussianLocalization`.
3. Скопируйте **все** файлы из этого репозитория в созданную папку.
4. Запустите игру и убедитесь, что в меню **Mods** русификатор включен.

## ✨ Основные особенности
- **Техническая исправность:** Все файлы в кодировке UTF-8 с BOM, переменные движка (=...=) полностью сохранены.
- **Умная грамматика:** Паттерны для корректного перевода боя, жидкостей (кровь, лава, ихор) и направлений.
- **Синхронизация с XML:** Все базовые термины игры (фракции, способности) переведены на основе официальных шаблонов.
- **Чистый лог:** Больше никаких "Франкенштейнов" (смеси языков) в типичных фразах.
