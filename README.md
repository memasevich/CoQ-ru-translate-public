# Caves of Qud — Русский перевод v1.0.6 (ПОД АКТУАЛЬНУЮ ВЕРСИЮ ИГРЫ 2.0.211.x)

Русификатор для игры Caves of Qud. Работает без Steam Workshop — просто скопируйте папку.

> ⚠️ Перевод заточен под актуальную версию игры (2.0.211.x, новая текстовая разметка). На старых версиях игры часть текстов может не переводиться!

## 🛠 Установка

1. **Скачивание:**
   - Нажмите зелёную кнопку `Code` → `Download ZIP`.
   - Распакуйте архив.

2. **Установка:**
   - В распакованном архиве найдите папку `RussianLocalization`.
   - Скопируйте её **целиком** в:
     `C:\Users\<ВашеИмя>\AppData\LocalLow\Freehold Games\CavesOfQud\Mods\`
   - Если папки `Mods` нет — создайте её вручную.
   - Должен получиться путь: `...\CavesOfQud\Mods\RussianLocalization\`

3. **Включение в игре:**
   - Запустите игру → Настройки → Моды → включите "Caves of Qud Russian Localization".

## 📦 Что внутри

- Полный словарь перевода (166 000+ строк) + паттерны и пословный словарь.
- Морфология: склонения существительных и прилагательных (файлы `forms_dictionary.json`, `stem_dictionary.json` — **не удаляйте их**, без них ломается согласование падежей).
- Перевод Popup-окон, меню, листа персонажа, инвентаря и подсказок нового интерфейса.

В мод встроен сборщик встреченного текста. Логи сохраняются в:
`C:\Users\<ВашеИмя>\Documents\CavesOfQud_RU_Logs`
